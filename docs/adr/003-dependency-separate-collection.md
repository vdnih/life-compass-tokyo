# ADR-003: イベント依存関係を別コレクションで永続化

**Date**: 2026-03-25
**Status**: 採用済み

## 背景

イベント間の依存関係（F-20）を永続化する方法として、イベントドキュメントへの埋め込みか、独立したコレクションかを選択する必要があった。

## 決定

依存関係はFirestoreの別コレクション（`users/{userId}/dependencies`）に保存する。MVPフェーズでは依存関係はインメモリで管理し、Firestore永続化はPhase 3（認証・データ同期）で実装する。

## 理由

- 依存関係をイベントドキュメントのサブフィールドとして埋め込むと、多対多の関係表現が困難
- 埋め込み方式では依存関係の横断的な検索・更新が非効率になる
- 独立コレクションにより、依存関係のCRUDをイベントと独立して管理できる

## 影響範囲

- `docs/FIREBASE_ARCHITECTURE.md` の `dependencies` コレクション定義
- セキュリティルール: `users/{userId}` 配下のワイルドカードルールで既にカバーされるため追加変更不要
