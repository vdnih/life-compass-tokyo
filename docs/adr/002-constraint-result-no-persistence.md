# ADR-002: 制約チェック結果の非永続化

**Date**: 2026-03-09
**Status**: 採用済み

## 背景

制約チェック（転職と産休・育休の期間制約など）の結果を、Firestoreに保存するかどうかを決定する必要があった。

## 決定

制約チェック結果（警告・情報メッセージ）はFirestoreに保存しない。イベント一覧から毎回算出する。

## 理由

- 制約結果はイベント一覧から算出可能な導出データであり、DBへの保存は冗長
- イベント変更のたびに制約結果を更新する整合性管理コストが高い
- MVP時点のイベント数（数十件規模）では毎回算出しても性能問題が発生しない（100ms以内）

## 影響範囲

- Firestoreのコレクション設計（`results` コレクション等は不要）
- セキュリティルールへの影響なし
