# ADR-004: ゴールテンプレート定義のハードコード

**Date**: 2026-03-25
**Status**: 採用済み

## 背景

ゴールテンプレート（出産テンプレート等）の定義をFirestoreに保存するかどうかを決定する必要があった。

## 決定

ゴールテンプレート定義はアプリ内にハードコードする。Firestoreには保存しない。テンプレートから生成されたイベントと依存関係のみFirestoreに保存する。生成後はテンプレートとの紐付けを保持しない（`isAutoGenerated` フラグで生成元の区別のみ行う）。

## 理由

- テンプレートはすべてのユーザーで共通の静的データであり、サーバーサイドに保存する利点がない
- アプリ更新時にテンプレートの追加・修正が可能であり、MVP時点ではこのアプローチで十分
- Firestoreへの保存はテンプレートのバージョン管理や同期の複雑性を生む

## 影響範囲

- テンプレート定義は `lib/` 配下にハードコード（具体的なパスは実装を参照）
- Firestoreのコレクション設計にテンプレート用コレクション不要
