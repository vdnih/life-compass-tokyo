## 1. イベントカテゴリ定義

`EventCategory` の各値と、対応する表示属性を定義する。

| category値 | isWork | 表示名 | アイコン概要 | カラー |
|---|---|---|---|---|
| `joining` | true | 入社 | ビル / ブリーフケース | Blue 600 |
| `jobChange` | true | 転職 | ビル / ブリーフケース | Blue 600 |
| `promotion` | true | 昇進・昇格 | 上矢印 / スター | Blue 400 |
| `maternityLeave` | true | 産休取得 | ハート / カレンダー | Pink 300 |
| `childcareLeave` | true | 育休取得 | チャイルド / カレンダー | Pink 200 |
| `returnToWork` | true | 復職 | リフレッシュ / 矢印 | Blue 500 |
| `retirement` | true | 退職 | ドア / 出口 | Grey 500 |
| `startup` | true | 起業 | フラッグ | Blue 300 |
| `certification` | true | 資格取得 | ワーク | Blue 200 |
| `sideJob` | true | 副業開始 | ワーク | Blue 200 |
| `marriage` | false | 結婚 | リング | Orange 400 |
| `childbirth` | false | 妊娠・出産 | ベビー / ハート | Pink 400 |
| `育児` | false | 育児 | ファミリー | Orange 300 |
| `caregiving` | false | 介護 | ハンド / ハート | Purple 300 |
| `moving` | false | 引越し | パーソン | Orange 200 |
| `travel` | false | 旅行 | パーソン | Orange 200 |
| `education` | false | 学び直し | パーソン | Orange 200 |

**設計根拠**: 女性のキャリア検討では、仕事とプライベートの境界にまたがるイベント（産休・育休など）が重要な意思決定要素となる。仕事側に「産休取得」「育休取得」「復職」を、プライベート側に「妊娠・出産」「育児」を設けることで、同一イベント（出産）の仕事面とプライベート面の両方を記録できる。

`isWork` 情報はアプリ側で `EventCategory.isWork` プロパティから導出する。Firestoreには保存しない（ADR-001参照）。

## 2. 制約チェックルール

制約チェックはクライアントサイドで実行する（ADR-005参照）。
制約チェック結果は永続化しない（ADR-002参照）。

| ID | 条件 | 種別 | メッセージ | Phase |
|---|---|---|---|---|
| C-01 | 「入社・転職」から1年未満に「妊娠・出産」または「産休取得」が存在 | 警告 (Warning) | 「転職から1年未満のため、育休が取得できない可能性があります」 | Phase 1 ✅ |
| C-02 | 「妊娠・出産」が登録されたが、1年以上前に「入社・転職」が存在しない | 情報 (Info) | 「出産予定の1年前までに転職を完了しておくと、育休取得がスムーズです」 | Phase 1 ✅ |
| C-03 | 依存関係のオフセット期間が確保されていない（前提イベントが結果イベントの後にある等） | 警告 (Warning) | 「{sourceEvent}と{targetEvent}の間に必要な期間（{offsetMonths}ヶ月）が確保されていません」 | Phase 2 ✅ |

**C-01 の根拠**: 育児・介護休業法では、労使協定により入社1年未満の従業員を育休の対象外とできる。

## 3. ゴールテンプレート定義

テンプレート定義はアプリ内にハードコードする。Firestoreには保存しない（ADR-004参照）。

### 3.1. 出産テンプレート

ゴール日を `T`（出産予定日）とした場合の自動生成イベント:

| # | 自動生成イベント | カテゴリ | 日付 | 終了日 | 依存タイプ | 説明 |
|---|---|---|---|---|---|---|
| 1 | 妊活開始 | private (その他) | T - 12ヶ月 | - | prerequisite | 出産の1年前を目安に妊活開始 |
| 2 | 転職リミット | work (jobChange) | T - 12ヶ月 | - | deadline | 育休取得のため、出産1年前までに転職完了が必要 |
| 3 | 海外旅行リミット | private (travel) | T - 4ヶ月 | - | deadline | 安定期を考慮した海外旅行の最終機会 |
| 4 | 産休開始 | work (maternityLeave) | T - 2ヶ月 | T | consequence | 産前6週間（約1.5ヶ月）から産休取得 |
| 5 | 出産（ゴール） | private (childbirth) | T | - | - | ゴールイベント本体 |
| 6 | 育休 | private (childcareLeave) | T | T + 12ヶ月 | consequence | 出産後〜最大1年間の育児休業 |
| 7 | 復職 | work (returnToWork) | T + 12ヶ月 | - | consequence | 育休終了後の職場復帰 |

- テンプレート適用後、各イベントは個別に編集・削除可能。
- ゴール日（出産予定日）を移動すると、全関連イベントがカスケード移動する。
