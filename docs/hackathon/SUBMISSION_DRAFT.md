### 2-3 サービスの詳細

ライフコンパス東京は、日本・東京都の制度上どんなライフプランが選べるかを示し、自分の人生をどう
したいか描けるようにするWebアプリです。結婚、妊娠、出産、育休、復職などの予定を一つの時間軸に置き、
イベント間のつながりを保ったまま何度でも描き直せます。育休の延長可能期間や産後パパ育休の取得条件
などの制度情報は、国・東京都いずれの制度かを明示し、出典・公式ページへのリンク付きで表示します。
対話型AIも同じ制度情報のみを根拠に答え、平均値のような比較を招く数値は扱いません。

### 2-4 着目した課題・背景

家庭もキャリアも全力でがんばりたい女性にとって、結婚・妊娠・出産・子育ては、どうしても
キャリアに影響しかねない制約です。制約自体を無くすことはできませんが、「制度上どこまで選べるか」
を知らないまま選択肢を狭めてしまう現実があります。特に、これからプランを立てたい20〜40代の女性
には、平均像に焦らされることなく、自分の権利と選べる余地を踏まえて考えるための枠組みが不足して
います。

### 2-5 課題・背景の解決方法

結婚・妊娠・出産・育休などの予定を同じタイムラインに置き、依存関係を保ったまま自由に描き直せる
ようにしました。日本の法令と東京都のオープンデータからは、育休が何年まで延ばせるかなど「制度上の
上限」だけを、実施主体（国／東京都）と出典付きで示し、平均値による比較は行いません。対話型AIも
同じ制度情報のみを根拠に答え、決定は常に利用者に委ねます。今後は、この画面を家庭で一緒に見て話す
きっかけとして育て、男性自身が体験するプログラムへの発展も構想しています。

## 3. 技術詳細

### 3-1 技術選定の理由

主要な利用環境であるWebに加え、将来のモバイル展開にも同じコードベースで対応できるFlutterを
採用しました。Firebase AuthenticationとCloud Firestoreは、ログイン利用者のデータ保存とゲスト
利用の導線を両立する基盤です。Firebase Hostingにより公開デモを継続的に提供しています。状態管理
にはRiverpodを用い、タイムライン・依存関係・制約チェックを分離し、予定変更時の連動を保守しやすく
しています。対話型AIにはFirebase AI Logic（Gemini、Function Calling）を採用しています。

### 3-2 生成AI等の活用方法（任意）

プロダクトでは、Gemini の Function Calling により、利用者の発話からタイムライン操作（テンプレート
の展開、イベント追加）と制度情報の照会を行う対話型AIを実装しました。AIが数値を自由に生成するのでは
なく、確認済みの制度上限データのみを関数経由で参照して説明する設計にしており、平均値のような比較を
招く数値はAIの発話対象から外しています。AIは選択を指示せず、利用者が自分の価値観と予定を整理する
ための対話相手として位置付けます。開発工程でも、要件・設計判断・テスト方針を文書化しながら
Claude Codeを活用しています。

## 4. オープンデータ利用状況

### 4-1 利用データ一覧

次のオープンデータ・法令情報を利用しています。アプリ内には各制度情報に実施主体（国／東京都）と
出典・公式ページへのリンクを表示します。

1. **東京都不妊検査等助成事業**
   - 提供元: 東京都福祉局
   - URL: <https://www.fukushi.metro.tokyo.lg.jp/kodomo/kosodate/josei/funinkensa/gaiyou.html>
   - ライセンス: 該当なし（公的な制度情報）
   - 使われ方: 検査開始日から申請できる期間（2年以内）を、実施主体「東京都」の制度上限として
     出典・公式ページへのリンク付きでタイムライン上に表示します。年齢等の対象要件は画面には出さず、
     公式ページの確認に委ねます。
   - 備考: 当初は東京デジタル2030ビジョン（こどもDX）子育て支援制度レジストリ
     （<https://catalog.data.metro.tokyo.lg.jp/dataset/t000029d0000000034>、CC BY 4.0）を出典候補
     としていましたが、同レジストリは国のレジストリ公開に伴い更新を終了しており、記載内容が
     現行制度と異なっていたため、東京都福祉局の公式ページを一次情報として採用しました。

2. **育児・介護休業法、労働基準法、母子保健法（厚生労働省・こども家庭庁の公式ページ）**
   - 提供元: 厚生労働省、こども家庭庁
   - ライセンス: 該当なし（公的な法令情報）
   - 使われ方: 育児休業の延長可能期間（子が2歳まで）、産前産後休業の期間、産後パパ育休、
     時間外労働の制限、子の看護等休暇、短時間勤務の利用可能期間を、実施主体「国」の制度上限として
     出典・公式ページへのリンク付きでタイムライン上に表示します。法令情報のため個別のオープン
     データライセンス表記はありませんが、公式ページのURLを常に併記します。

統計をランキング、比較、行動の指示には使いません。平均値・中央値は利用者の目に触れる場所には出さず、
テンプレート初期値の内部根拠にとどめます。データの出典・実施主体を常に確認できる形で示し、利用者が
自分の価値観に沿って判断できるようにします。
