# PDR-005: 規定ライフイベントカタログD&D方式へのピボット

**Date**: 2026-05-12
**Status**: 採用済み
**Owner**: Product Manager / Architect Agent

## 背景

リリース前の本アプリは「16カテゴリ（仕事8 + プライベート8）から自由にイベントを追加する」UIで運用してきた。
ユーザーリサーチ（プロダクトオーナー自身による検証含む）とMVV v0.2 適用後の見直しにより、以下が明らかになった。

- 「カテゴリを選んでタイトルを自由記述する」入口がユーザーにとって**最初の摩擦**になっている。
  ライフプランをこれから初めて描こうとする20代後半〜30代前半女性にとっては、
  「何のイベントを書けばいいのか」自体が思いつかない。
- カテゴリ16種類は分類のための装置であって、ユーザーが行いたい「自分の人生に起こり得るイベントを並べる」体験とは
  ずれていた。
- 産休・育休と転職の関係のような **イベント間の前後関係や推奨期間** は、現状はC-01〜C-03の3ルールでしか
  表現できておらず、結婚・出産・住まい・キャリアの相互作用を網羅できていない。
- ライフイベントには現実的に予算（結婚式 / 新婚旅行 / 出産費用 など）が伴うが、現UIは金額の概念を持たない。

## 決定

以下にプロダクトをピボットする。

1. **規定ライフイベントカタログ × ドラッグ&ドロップ** をメインの入口にする。
   - 左パネルにグループ別（結婚 / 出産 / キャリア / 住まい / 旅行 / 学び / お金）のカタログを表示し、
     項目をタイムラインへドラッグして配置する。
   - 既存16カテゴリは廃止し、カタログのID（`catalogId`）で各イベントを識別する。
2. **マイルストーンを LifeEvent の子要素** として表現する（`parentEventId`）。
   - 例: 「結婚式」の下に「式場選び」「式場決定」「衣装合わせ」などの小さなイベント。
3. **規定イベントごとに hard 先行 / soft 先行を事前定義** する。
   - hard = 物理的・法的に成立しない順序（入籍はプロポーズの後 / 育休は出産の後 など）。
   - soft = 慣習・準備期間として推奨（結婚式は式場決定から半年以上 など）。
   - UI上は hard 違反 = 赤、soft 違反 = 黄でフィードバックし、ブロックはしない（Value 4: Empowerment, not Direction）。
4. **予算プリセット** を規定イベントに付与する。
   - 中央値をプリセット表示し、ユーザーは自由に上書きできる。
   - AppBar に合計予算サマリを表示する。
5. **初版スコープのターゲットを 20代後半〜30代前半女性に絞る**。
   - 同棲〜結婚周りを最重点、続いて出産 / キャリア / 海外旅行を充実させる。
   - **介護グループは初版から除外する**（ターゲット外で、誤って提示するとプレッシャーを生む）。

## 理由

- **Compass, not a Mirror**: 規定カタログは「他者と比較するためのテンプレート」ではなく、
  「自分の人生に起こり得る選択肢を提示する地図」として機能する。検索性と発見性を担保するために、
  プロダクト側がカタログを用意する。
- **Living Plan**: D&D操作はキーボード入力よりも軽い意思表示で、配置・移動・削除を躊躇なく繰り返せる。
  「とりあえず置いてみる→違ったらドラッグで動かす」の体験を最大化する。
- **First-class Citizen**: 結婚 / 出産 / 妊活 / 育休 / 復職 を **キャリアと並列のグループ** として
  カタログに固定配置することで、これらが「例外」ではなく「人生の主要な選択肢」であることをUIで明示する。
- **Empowerment, not Direction**: hard / soft はあくまで情報提供。ドロップは常に許可され、
  メッセージは「〜の目安です」「〜が確保できると◯◯しやすい」など事実提供口調に統一する。

## スコープ

### 初版（Phase 2 内）に含めるグループ

| グループ | 件数目安 | 重点理由 |
|---|---|---|
| 結婚 (marriage) | 10〜12件 | ターゲット層の最重要関心領域。同棲〜入籍〜結婚式〜新婚旅行までを細かく刻む |
| 出産 (childbirth) | 6〜8件 | 妊活〜産休〜育休〜復職の連鎖を可視化することが本プロダクトの中核価値 |
| キャリア (career) | 6〜8件 | 入社・転職・昇進・起業・資格・副業・退職 |
| 住まい (lifestyle) | 5件 | 引越し・賃貸更新・住宅購入検討・住宅購入・リフォーム |
| 旅行 (travel) | 3〜5件 | 海外旅行 / 長期旅行 / ワーケーション / 留学 |
| 学び (learning) | 3〜4件 | 資格勉強開始 / 学位取得 / 語学留学 |
| お金 (money) | 3件 | NISA開始 / iDeCo開始 / 保険見直し |

### スコープ外

- **介護グループ**: ターゲットが20代後半〜30代前半女性のため、現時点では設計に含めない。
  将来、ターゲットを40代以降に広げる際に別PDRで再検討する。
- **複数シナリオ比較**: 既存PRDの将来構想として保持。本ピボットでは扱わない。
- **テンプレート市場 / ユーザー定義カタログ**: ADR-004（テンプレートのハードコード）方針を維持。
