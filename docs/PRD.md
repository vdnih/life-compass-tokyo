# ライフプランアプリ プロダクト要件定義書 (PRD)

**Version**: 5.1
**Last Updated**: 2026-03-29
**Owner**: Architect Agent

## 1. プロダクトビジョン

女性が自身のキャリアとプライベートの両面から、ライフゴールを設定し、
そこから逆算して必要なイベントやタイミングを計画するためのタイムラインアプリ。

**コアコンセプト**: 「目標から逆算して、わたしの人生をデザインする。その目標は、いつでも描き直せる。」

プロジェクトマネジメントのように、ゴール（マイルストーン）を設定し、
そこから逆算して必要なタスクやイベントを時系列に配置していく。
イベント同士の依存関係を可視化し、1つのイベントを動かすと関連イベントも連動して移動する。

## 2. ターゲットユーザー

- 20〜40代の女性
- キャリアとプライベートの両立を考えている方
- 人生の転機（転職、結婚、出産など）を見据えて計画を立てたい方
- 過去の経験を整理し、将来の選択に活かしたい方
- 産休・育休と転職のタイミングを戦略的に検討したい方
- ライフゴールを設定し、そこから逆算して計画を立てたい方

## 3. 機能一覧

各機能の詳細仕様はコードおよび `docs/SPEC.md` を正とする。

### Phase 1 - MVP（リリース済み）

| ID | 機能名 | 概要 |
|---|---|---|
| F-01 | タイムライン表示 | 横スクロール型タイムライン（仕事/プライベート2レーン、年月・年ビュー切替） |
| F-02 | イベント管理 | イベントの追加・削除。カテゴリ定義は `docs/SPEC.md` 参照 |
| F-03 | プロフィール設定 | ユーザー名・生年月日の設定 |
| F-10 | ライフイベント制約の可視化 | 転職と産休・育休の制約チェックと警告表示。ルール定義は `docs/SPEC.md` 参照 |
| F-MVP-DATA | データ永続化（ローカル） | MVPはインメモリ。Repository層はFirestore移行を見据えた設計 |

### Phase 2 - 目標逆算機能（実装済み）

| ID | 機能名 | 概要 |
|---|---|---|
| F-06 | イベント編集 | 既存イベントの編集。日付変更時はカスケード移動が発動 |
| F-20 | イベント依存関係 | イベント間の依存関係管理（前提・結果・期限・連動）。循環依存は拒否 |
| F-21 | ゴールテンプレート | ゴール日設定で関連イベントを一括生成。テンプレート定義は `docs/SPEC.md` 参照 |
| F-22 | ドラッグ&ドロップ移動 | イベントのドラッグ移動。依存イベントのカスケード移動 |
| F-23 | 依存関係の可視化 | 依存イベント間をコネクタ線で表示 |

### Phase 3 - 将来構想（スコープ外）

- F-04: ユーザー定義カテゴリ
- F-05: 将来計画モード
- F-07: Firebase連携・データ永続化（認証、Firestore同期、マルチデバイス対応）
- F-08: メモ・振り返り機能
- F-09: 追加テンプレート（転職、起業など）
- F-11: キャリアブランク影響の可視化
- F-12: 制約チェッカー（高度版）
- F-24: 逆算タイムライン表示
- 年収推移シミュレーション、ライフプラン複数パターン比較（自分自身の複数シナリオ比較のみ。他者との比較はスコープ外）

## 4. 非機能要件

- レスポンシブ対応（スマートフォン + タブレット + Web）
- オフラインファースト（Phase 3のFirebase連携時もローカル優先）
- アクセシビリティ配慮（十分なコントラスト比、スクリーンリーダー対応）
- 制約チェックの応答時間: 100ms以内
- カスケード移動の応答時間: 200ms以内

## 5. デザイン方針

- 仕事イベント: ブルー系
- プライベートイベント: オレンジ系
- 産休・育休関連: ピンク系
- 制約警告: Amber系
- 制約情報: Light Blue系
- ゴールイベント: Purple 400
- 基調: blueGrey
