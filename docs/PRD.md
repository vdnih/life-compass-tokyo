# ライフプランアプリ プロダクト要件定義書 (PRD)

**Version**: 2.0
**Last Updated**: 2025-XX-XX
**Owner**: Architect Agent

## 1. プロダクトビジョン

女性が自身のキャリアとプライベートの両面から、これまでの歩みとこれからの人生を俯瞰的に見つめ、
主体的にライフプランを考えるためのタイムラインアプリ。

**コアコンセプト**: 「わたしの人生を、一本のタイムラインに。」

## 2. ターゲットユーザー

- 20〜40代の女性
- キャリアとプライベートの両立を考えている方
- 人生の転機（転職、結婚、出産など）を見据えて計画を立てたい方
- 過去の経験を整理し、将来の選択に活かしたい方

## 3. 機能定義

### 3.1. MVP（Phase 1 - 現在のスコープ）

> **注意**: Implementerはこのスコープ内の機能のみを実装すること。スコープ外はTODOコメントに留める。

#### F-01: タイムライン表示
- 横スクロール型のタイムラインで、仕事（Work）とプライベート（Private）の2レーンを表示する。
- 年月ビュー（詳細）と年ビュー（俯瞰）の切り替えができる。
- 生年月日設定時、時間軸上に年齢を表示する。

#### F-02: イベント管理
- イベントの追加・削除ができる。
- イベント種別: 仕事（Work）/ プライベート（Private）
- 各イベントに設定可能な項目:
  - タイトル（必須、最大50文字）
  - 詳細（任意、最大500文字）
  - 開始年月（必須）
  - 終了年月（任意）
  - アイコン種別（仕事のみ: 入社・キャリアアップ・目標）

#### F-03: プロフィール設定
- ユーザー名の設定（最大20文字）
- 生年月日の設定（年齢自動計算に使用）

#### F-MVP-DATA: データ永続化（ローカル）
- MVPではインメモリ（アプリ再起動でデータ消失を許容）
- Repository層のインターフェースはFirestore移行を見据えた設計にしておく

### 3.2. Phase 2（次期開発 - スコープ外）

- F-04: ライフイベントカテゴリの拡充
- F-05: 将来計画モード（過去と将来の視覚的区別、ステータス付与）
- F-06: イベント編集機能

### 3.3. Phase 3（将来構想 - スコープ外）

- F-07: Firebase連携・データ永続化（認証、Firestore同期、マルチデバイス対応）
- F-08: メモ・振り返り機能
- F-09: テンプレート機能

## 4. 画面構成

### 4.1. タイムライン画面（メイン画面）
- **AppBar**: アプリ名 + ユーザー名(年齢) + ビュー切替ボタン + プロフィール設定アイコン
- **Body**: 横スクロールタイムライン（上段: 仕事レーン / 下段: プライベートレーン）
- **FAB**: イベント追加ボタン（+アイコン）

### 4.2. イベント追加ダイアログ
- 種別選択（仕事 / プライベート）
- タイトル入力フィールド
- 詳細入力フィールド
- 開始年月ピッカー
- 終了年月ピッカー（任意）
- アイコン種別選択（仕事の場合のみ表示）

### 4.3. プロフィール設定ダイアログ
- ユーザー名入力フィールド
- 生年月日ピッカー

## 5. 非機能要件

- レスポンシブ対応（スマートフォン + タブレット + Web）
- オフラインファースト（Phase 3のFirebase連携時もローカル優先）
- アクセシビリティ配慮（十分なコントラスト比、スクリーンリーダー対応）

## 6. デザイン方針

- 仕事イベント: ブルー系 (`Colors.blue`)
- プライベートイベント: オレンジ系 (`Colors.orange`)
- 基調: blueGrey（MVPはデフォルトテーマ、Phase 2以降で温かみのあるトーンに変更検討）
- シンプルで直感的なUI
