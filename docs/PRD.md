# ライフプランアプリ プロダクト要件定義書 (PRD)

**Version**: 6.0
**Last Updated**: 2026-05-12
**Owner**: Architect Agent

## 1. プロダクトビジョン

女性が自身のキャリアとプライベートの両面から、ライフゴールを設定し、
そこから逆算して必要なイベントやタイミングを計画するためのタイムラインアプリ。

**コアコンセプト**: 「目標から逆算して、わたしの人生をデザインする。その目標は、いつでも描き直せる。」

v6.0 ピボットの方針（PDR-005 参照）:

- **規定ライフイベントカタログ × ドラッグ&ドロップ** をメインの入口にする。
- 「自由なカテゴリ入力」をやめ、規定カタログから選んでタイムラインへ配置する体験に切り替える。
- 規定イベントごとに **hard / soft** の前後関係と **予算プリセット**、**既定マイルストーン** を持たせる。

## 2. ターゲットユーザー

### Primary（初版スコープ）

- **20代後半〜30代前半の女性**
- 同棲・結婚・出産・キャリア形成・住まい・旅行の検討期にいる
- ライフプランを描きたいが、何から考えればいいか分からない

### Secondary

- 20〜40代の女性全般
- キャリアとプライベートの両立を考えている方
- 人生の転機を見据えて計画を立てたい方

### 意図的にスコープ外

- **介護グループ**: 初版のターゲット層と関心領域が外れるため、本リリースでは扱わない（PDR-005 参照）
- 他者との比較・SNS的要素（PRODUCT_VISION.md Value 1: Compass, not a Mirror）

### Phase 4 - 将来構想（スコープ外）

- F-24: 逆算タイムライン表示
- 年収推移シミュレーション、ライフプラン複数パターン比較（自己シナリオ限定）
- 介護グループのカタログ追加（ターゲットを40代以降に広げる際に再検討）

## 4. 非機能要件

- レスポンシブ対応（スマートフォン + タブレット + Web）
- オフラインファースト（Firebase連携時もローカル優先）
- アクセシビリティ配慮（十分なコントラスト比、スクリーンリーダー対応）
- 制約チェックの応答時間: 100ms以内
- カスケード移動の応答時間: 200ms以内
- D&D操作中のフィードバック更新: 60fps（hard / soft 違反プレビューはドラッグ中にリアルタイム描画）

## 5. デザイン方針

- グループ別のカラーは規定カタログ定義側で持つ（`PredefinedLifeEvent.color`）
- 産休・育休関連: ピンク系（First-class Citizen として通常イベントと同等の存在感）
- hard 違反: 赤系
- soft 違反: 黄系（Amber）
- ゴールイベント: Purple 400
- 基調: blueGrey
