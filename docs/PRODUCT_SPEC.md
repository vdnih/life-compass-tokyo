# ライフプランアプリ プロダクト仕様書

**Version: 1.0**

## 1. プロダクトビジョン

女性が自身のキャリアとプライベートの両面から、これまでの歩みとこれからの人生を俯瞰的に見つめ、
主体的にライフプランを考えるためのタイムラインアプリ。

## 2. ターゲットユーザー

- 20〜40代の女性
- キャリアとプライベートの両立を考えている方
- 人生の転機（転職、結婚、出産など）を見据えて計画を立てたい方
- 過去の経験を整理し、将来の選択に活かしたい方

## 3. コアコンセプト

**「わたしの人生を、一本のタイムラインに。」**

キャリア（仕事）とプライベート（生活）の出来事を一つのタイムライン上に並べることで、
自分の人生全体を可視化する。過去の記録だけでなく、将来の計画や目標も書き込むことで、
「これからどう生きたいか」を考えるためのツールとなる。

## 4. 機能一覧

### 4.1. MVP（現在のスコープ）

#### F-01: タイムライン表示
- 横スクロール型のタイムラインで、仕事とプライベートの2レーンを表示
- 年月ビュー（詳細）と年ビュー（俯瞰）の切り替え
- 時間軸上に年齢を表示（生年月日設定時）

#### F-02: イベント管理
- イベントの追加・削除
- イベント種別: 仕事（Work）/ プライベート（Private）
- 各イベントに開始年月、終了年月（任意）、タイトル、詳細を設定可能
- 仕事イベントにはアイコン種別（入社・キャリアアップ・目標）を設定可能

#### F-03: プロフィール設定
- ユーザー名の設定
- 生年月日の設定（年齢自動計算に使用）

### 4.2. Phase 2（次期開発）

#### F-04: ライフイベントカテゴリの拡充
- 仕事系: 入社、転職、昇進、退職、起業、資格取得、副業開始
- プライベート系: 結婚、出産、育休、復職、引越し、旅行、学び直し、介護
- カテゴリごとのアイコンとカラー

#### F-05: 将来計画モード
- 「過去の記録」と「将来の計画」を視覚的に区別
- 計画イベントには「予定」「目標」「検討中」のステータスを付与可能
- 現在時点を示すマーカーをタイムライン上に表示

#### F-06: イベント編集
- 既存イベントの内容を編集する機能

### 4.3. Phase 3（将来構想）

#### F-07: Firebase連携・データ永続化
- ユーザー認証（メール/パスワード）
- Firestoreへのデータ保存・同期
- 複数デバイス間のデータ同期

#### F-08: メモ・振り返り機能
- 各イベントにメモや気持ちを記録
- 定期的な振り返りリマインダー

#### F-09: テンプレート機能
- 一般的なライフイベントのテンプレートを提供
- 「30歳までにやりたいこと」などの目標テンプレート

## 5. 画面構成

### 5.1. タイムライン画面（メイン）
- AppBar: アプリ名 + ユーザー名(年齢) + ビュー切替 + プロフィール設定
- Body: 横スクロールタイムライン（仕事レーン / プライベートレーン）
- FAB: イベント追加

### 5.2. イベント追加ダイアログ
- 種別選択（仕事 / プライベート）
- タイトル・詳細入力
- 開始年月選択
- 期間指定（任意）
- 仕事の場合: アイコン種別選択

### 5.3. プロフィール設定ダイアログ
- ユーザー名入力
- 生年月日選択

## 6. 非機能要件

- オフラインファースト（Phase 2以降のFirebase連携時もローカル優先）
- レスポンシブ対応（スマートフォン + タブレット + Web）
- アクセシビリティ配慮（十分なコントラスト比、スクリーンリーダー対応）

## 7. デザイン方針

- 温かみのある配色（現在のblueGrey基調から、より柔らかいトーンへ Phase 2以降で検討）
- 仕事イベント: ブルー系
- プライベートイベント: オレンジ系
- シンプルで直感的なUI
